# نظام – تطبيق iPhone

تطبيق ويب عربي من نوع PWA (Progressive Web App) مناسب للايفون، ويشتغل كـ app على الشاشة الرئيسية.

## التشغيل

1. افتح `index.html` في المتصفح.
2. في Safari على الآيفون: اضغط على زر المشاركة.
3. اختر "إضافة إلى الشاشة الرئيسية".
4. افتح التطبيق الجديد من الشاشة الرئيسية.

## المميزات

- شاشة رئيسية
- مواقيت الصلاة
- الأذكار
- مؤقت المذاكرة
- المهام
- الإحصائيات
- حفظ الآيات
- تنبيهات وقت الصلاة
- تصميم RTL عربي
- يتوافق مع iPhone / Safari

## الملفات

- `index.html` — التطبيق الرئيسي
- `manifest.webmanifest` — إعدادات التطبيق
- `sw.js` — خدمة عمل (offline cache)

## ملاحظات

- هذا تطبيق ويب يصلح للـ iPhone دون Apple Developer.
- لإضافة أيقونة مخصصة، استخدم صور 192x192 و512x512 باسم `icon-192.png` و`icon-512.png` داخل نفس المجلد.
